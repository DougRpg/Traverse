Traverse: Starlight & Prairie
English and Brazilian Portuguese translation patches
Patches de tradução para o inglês e para o português do Brasil

Super Famicom, Banpresto / Pandora Box, 1996
Translation / Tradução: DougRPG
2026-11-11

Version 1.0.0

ENGLISH

1. Get the original Japanese ROM of the game. The patches only work on it:
   4,194,304 bytes (4 MiB), no copier header
   CRC32 B5113CCB
   SHA-1 47d94a325a87fd476a3b1e0850222f359b081998

2. Choose a patch. IPS and BPS give the same ROM; the BPS also checks the
   original ROM before patching.

   traverse_en.ips / traverse_en.bps

3. Apply it with an IPS/BPS patcher, such as Flips (Floating IPS) or Beat.

The patched ROMs:
   traverse_en.sfc          CRC32 F1E9C6D4

If possible, play on the RetroLab platform (retrolab.games), where you can generate a shareable link that will take anyone who opens it directly to the point where the link was created, which helps with debugging.


PORTUGUÊS

A versão em português se chama Traverse: Luz das Estrelas & Pradarias.

1. Consiga a ROM original japonesa do jogo. Os patches só funcionam nela:
   4.194.304 bytes (4 MiB), sem o cabeçalho de copiadora
   CRC32 B5113CCB
   SHA-1 47d94a325a87fd476a3b1e0850222f359b081998

2. Escolha um patch. O IPS e o BPS dão a mesma ROM; o BPS ainda confere a
   ROM original antes de aplicar.

   traverse_pt.ips / traverse_pt.bps

3. Aplique com um programa de patches IPS/BPS, como o Flips (Floating IPS) ou o Beat.

As ROMs com o patch:
   traverse_pt.sfc  CRC32 FA7017E8

Se possível jogue na plataforma RetroLab (retrolab.games), e lá é possível gerar um link compartilhável onde quem abrir vai direto para o ponto onde o link foi criado, o que ajuda no debug.
